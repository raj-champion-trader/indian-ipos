# Valiant Laboratories Limited (VALIANTLAB)

## What it does
Valiant Laboratories makes paracetamol API (the pain-and-fever powder inside crocin-style tablets) at a plant in Gujarat. It sells this powder to drug makers in India and abroad. The company listed via IPO in October 2023.

## The numbers
- Revenue: Rs 334 crore FY23; Rs 182 crore FY24; Rs 133 crore FY25 (standalone, screener). Consolidated FY24 ~Rs 182 crore, FY25 ~Rs 133 crore (India Ratings).
- PAT: Rs 29 crore FY23; ~Rs 0 crore FY24; net loss ~Rs 2 crore FY25. TTM PAT ~Rs 13 crore on sales of ~Rs 239 crore.
- OPM: 11% FY23 to -3.5% FY25; TTM ~7%.
- Nearly debt-free; debtor days ballooned to 197 (Mar 2025). Stock P/E ~41.

## Lynch lens
Cyclical/turnaround hybrid — API prices cycle hard, and FY25 marked the trough. Paracetamol smells like a boring commodity niche, but the company lacks pricing power (9M FY25 operating loss of Rs 8.5 crore per Crisil). PEG meaningless at trough earnings; P/E 41 on depressed profit prices in recovery. Q1 FY26 revenue Rs 74 crore, up 44% YoY — watch the cycle turn, not the multiple.

## TAM
Indian paracetamol API market: data not found precisely; global paracetamol API market estimated in the low single-digit billion USD (industry estimates) — treat as approximate.

## Top 3 P/L drivers
1. Paracetamol API realisation/pricing cycle (single-product concentration).
2. Raw material cost (para-aminophenol / phenol linked to crude).
3. Capacity utilisation of the new Bharuch plant plus receivable collection (197 debtor days).

## Red flags
One-product company; FY25 net loss; wild debtor days; IPO-timing at peak cycle; TTM recovery could reverse if Chinese API prices fall again.

## Verdict
A bottom-of-the-cycle commodity bet — only interesting if the paracetamol price cycle turns and stays up.
